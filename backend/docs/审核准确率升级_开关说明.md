# 审核准确率升级 — 三个 opt-in 开关

> 背景：平台审核不如人工直审的三个结构性根因（输入无版式 / 无跨块上下文 / 过滤器一刀切删除）。
> 三项改动全部**默认关闭**，不设环境变量时流水线行为与改动前完全一致（零回归）。
> 代码：`app/review_engine/accuracy_upgrades.py`；测试：`tests/test_accuracy_upgrades.py`（8 例）。

## 1. 全页几何疑点提示 — `REVIEW_FULLPAGE_GEOMETRY_HINTS`

- **解决**：视觉复核只看 6+6 页，其余页的拥挤/粗线/图片偏离中心没人看。
- **做法**：用已有 `pdf_layout_signals`（纯 fitz、不烧模型 key）扫描**所有页**，对达到阈值的页产 `PDF-GEOM-HINT-001`。
- **安全约束（C3）**：只产 `needs_human_review` 提示，`confidence=68`（<85），绝不作为高置信自动判错；
  只处理三类纯几何信号（行距过密≥0.75 / 表格线过粗≥0.35 / 图片偏离中心≥0.28），
  **不碰已裁定为提取伪影的"图标/按钮缺失"**。
- **开启**：`REVIEW_FULLPAGE_GEOMETRY_HINTS=1`
- **代价**：会多出若干"待人工复核"提示（不是误报，但需人工看）。建议先在小文档上试。

## 2. 全文术语一致性索引 — `REVIEW_FULLTEXT_CONSISTENCY_PASS`

- **解决**：AI 分块审，每块看不到别块，跨章节术语不一致无法判断。
- **做法**：审前从全文抽"已知易混写法对"（存储/储存、其它/其他、帐号/账号…）与"缩写/全称并存"
  （Catalog Number / Cat. No.、PCR / Polymerase Chain Reaction），注入各分块审核依据。
- **安全约束**：只提供候选索引（"仅供比对，非结论"），不额外调用模型、不增加 token 成本，
  是否报问题仍由主审核链按证据裁定。
- **开启**：`REVIEW_FULLTEXT_CONSISTENCY_PASS=1`
- **代价**：prompt 略变长（≤60 条索引）；术语噪声多的文档可能提示一些无需报的比对。

## 3. 一刀切过滤改为降权保留 — `REVIEW_KEEP_DOWNGRADED_ISSUES`

- **解决**：`is_noise` / `value_score` 的整类规则与阈值过滤是**静默删除**，人工能判断的真语义问题被直接丢掉。
- **做法**：原本要 drop 的 issue，改为 `confidence=40` + `needs_human_review` + `possible_false_positive` + `downgrade_reason` 保留，
  排在高置信结果之后。
- **安全约束**：与现有误报降权设计一致（不硬删、交人工）；默认关，避免误报涌入主结果。
- **开启**：`REVIEW_KEEP_DOWNGRADED_ISSUES=1`
- **代价**：结果条数会明显增加（被过滤的都回来了），precision 口径会下降——这是 recall 换 precision 的取舍，
  **必须在补好 goldset 之后才建议开**，否则无法验证效果。

## 建议启用顺序

1. 先开 `REVIEW_FULLTEXT_CONSISTENCY_PASS`（零额外成本、零新误报风险）。
2. 再开 `REVIEW_FULLPAGE_GEOMETRY_HINTS`，观察"待人工复核"提示是否有价值。
3. `REVIEW_KEEP_DOWNGRADED_ISSUES` 最后开，且先补 goldset。
