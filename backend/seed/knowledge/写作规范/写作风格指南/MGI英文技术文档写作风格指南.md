# MGI英文技术文档写作风格指南

本文件整理自项目现有的英文技术写作规范，供审核模块作为英文文档风格依据使用。

## Language

### Tense

- Use present tense in most cases.
- Use future tense only when necessary.
- Prefer direct task-oriented instructions.

Examples:

- MGI style: After you power on the device, self-test begins.
- Non-MGI style: After you power on the device, the self-test will begin.
- MGI style: If you open the door, the sequencing run stops.
- Non-MGI style: If you open the door, the sequencing run will be stopped.

### Voice

- Use active voice in most cases.
- Rewrite sentences when forms of "to be" are overused.
- Use passive voice when the action performer is unknown or unimportant.

Examples:

- MGI style: You can prepare libraries manually or use the third-party systems.
- Non-MGI style: The library can be prepared manually or using third-party systems.
- MGI style: In the wash interface, tap Wash. A confirmation dialogue box is displayed.

### Tone

- Keep the tone helpful, direct, and confident.
- Use concrete and accurate information.
- Prefer short and explicit wording.

Examples:

- MGI style: The air inlet and internal air filter unit enable air to circulate in the device to ensure proper cooling.
- Non-MGI style: This is the air inlet for air filter unit.
- MGI style: Take out the obsolete PCR board and discard it into a specified biological hazard waste can that has a biological hazard symbol.
- Non-MGI style: Take out the obsolete PCR board and discard it into a specified biological hazard waste can.

### Version of English

- Use American English for all technical documents.

## Grammar

### Articles

- Do not omit the definite article before attributive clauses.
- Use "the" when a noun has already been mentioned.
- Use "the" for a specific object known to the reader.

Examples:

- MGI style: Holds flow cell B and controls the temperature that is required for biochemical reaction.
- Non-MGI style: Holds flow cell B and controls temperature that is required for biochemical reaction.
- MGI style: If the problem still persist, contact Technical Support for help.
- Non-MGI style: If problem still persist, contact Technical Support for help.

### Indefinite article

- Use "a" before words that begin with a consonant sound.
- Use "an" before words with a vowel sound.
- Choose "a/an" according to how an abbreviation is spoken.

Examples:

- a university
- a UPS
- an MGI self-developed software
- an HTML document

### No article

- Use plurals and uncountable nouns to describe things in general.
- Do not use articles with proper nouns, including companies, universities, languages, holidays, and most place names.

Examples:

- MGI style: Recycling information for China.
- Non-MGI style: Recycling information for the China.
- MGI style: The original document was written in English.
- Non-MGI style: The original document was written in the English.

### Abbreviations and acronyms

- Include technical terms, acronyms, and abbreviations in the glossary.
- Use parentheses to enclose the abbreviation the first time it is mentioned.
- Use abbreviations when space is limited or the abbreviation is widely understood.
- Avoid abbreviations when they appear only once or their meaning is ambiguous.
- Add lowercase "s" for plural abbreviations.
- Do not use abbreviations as verbs.
- Do not use Latin abbreviations in formal technical writing.

Examples:

- MGI style: a PDF document
- Non-MGI style: a Portable Document Format document
- MGI style: You can use the FTP command to send the files to the server.
- Non-MGI style: You can FTP the files to the server.
- MGI style: sample IDs
- Non-MGI style: sample IDS

### Capitalization

- Use sentence style for headings, captions, interface labels, and general text.
- Ensure capitalization is consistent.
- Use capitalization for proper nouns, trademarks, product names, and exact interface labels.
- Do not capitalize common nouns without a product or UI meaning.

Examples:

- MGI style: About the user manual
- Non-MGI style: About the User Manual
- MGI style: Figure 3 Front view
- Non-MGI style: Figure 3 Front View

## Numbers and measurements

- Keep numbers and units consistent across the document.
- Follow standard unit spelling and case.
- Use the same spacing pattern for equivalent measurements.
- Do not pluralize units of measurement in abbreviations.

Examples:

- 1 mm
- 10 μL
- 30 min
- 4 h

## Spelling and wording

- Use standard product and scientific terms consistently.
- Keep the same spelling for the same concept throughout the document.
- Prefer exact wording over conversational phrasing.

## Sentences

- Keep sentences concise.
- Avoid stacked modifiers and repeated nouns.
- Split long instructions into shorter actions when needed.

## Review focus

- Tense and voice consistency
- Article usage
- Capitalization consistency
- Abbreviation introduction and plural form
- Number and unit formatting
- Sentence clarity and directness
