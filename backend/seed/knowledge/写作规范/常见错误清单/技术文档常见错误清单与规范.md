# 技术文档常见错误清单与规范

本清单用于确保技术文档、说明书和快速操作指南的准确性、一致性和专业性，供审核模块识别高频低级错误。

## 标点符号

| 错误类型 | 错误举例 | 正确示范 |
| --- | --- | --- |
| 中英文标点符号混用 | 中文文档使用半角逗号`,`和句号`.` | 中文文档统一使用全角标点，代码、命令、参数和英文内容使用半角标点 |
| 英文标点符号后缺空格 | `,open the door.` | `, open the door.` |
| 标点符号重复 | `Place the tube on the operation deck..` | `Place the tube on the operation deck.` |
| 标点符号缺失 | `Click the button to stop the sequencing run` | `Click the button to stop the sequencing run.` |
| 标点符号缺一半 | `Insert “Cartridge1.` | `Insert “Cartridge1".` |
| 标点符号方向错误 | `”ON" (power)` | `"ON" (power)` |
| 标点后多余空格 | `Contact  the technical support.   For details...` | `Contact the technical support. For details...` |
| 上角标位置错误 | `Qubit® / DNBSEQTM` | `Qubit^®^ / DNBSEQ^TM^` |
| 下角标位置错误 | `OD260/OD280=1.8 ~ 2.0` | `OD~260~/OD~280~=1.8 ~ 2.0` |

## 错别字

| 错误类型 | 错误举例 | 正确示范 |
| --- | --- | --- |
| 关键状态描述错误 | `设备以停止工作` | `设备已停止工作` |
| 警示与禁止混淆 | `切忌远离水源` | `切记远离水源` 或 `禁止靠近水源` |
| 试剂与硬件混淆 | `按比例配置 80 mL 80% 浓度酒精溶液` | `按比例配制 80 mL 80% 浓度酒精溶液` |
| 动词混淆 | `震荡混匀` | `振荡混匀` |
| 仓字混淆 | `试剂舱` | `试剂仓` |
| 技术规格储存统一描述 | `存储` | `储存` |
| 移液器写法错误 | `Pipets` | `Pipettes` |

## 共性问题

| 错误类型 | 错误举例 | 正确示范 |
| --- | --- | --- |
| 中国 ROHS 表格名称更新 | `产品中有害物质的名称及含量` | `产品中有害物质的名称及含有信息表` |
| 欧代标识更新 | `EC REP` | `EU REP` |
| 海外官网地址变化 | `www.mgi-tech.com` | `https://global-mgitech.com` |
| 注意章节统一描述 | `您有其他疑问，请联系技术支持` | `若您有其他疑问，请联系技术支持` |
| 中英夹杂 | `Cat. No.` 出现在中文说明书 | 中文场景统一使用 `货号` |
| 英文界面字符串未加粗 | `Click Continue.` | `Click **Continue**.` |
| 扉页商标声明缺失或多余 | 扉页列出商标，正文无对应产品信息 | 扉页商标声明应与正文实际出现内容一致 |
| 修订历史表格月份缩写 | `Mar. 2026` | `March 2026` |

## 单位

| 错误类型 | 错误举例 | 正确示范 |
| --- | --- | --- |
| 微升单位错误 | `ul` | `μL` |
| 毫升单位错误 | `ml` | `mL` |
| 单位误用复数 | `mins`, `hs` | `min`, `h` |
| 秒缩写错误 | `sec` | `s` |
| 单位大小写错误 | `Kg` | `kg` |

## 审核关注点

- 中文标点与英文标点的使用边界
- 英文标点后的空格和重复标点
- 中文错别字与术语写法
- 官网地址、欧代、ROHS、商标声明等固定表述
- 中英文混写场景下的中文替代词
- 单位缩写、大小写和空格一致性
