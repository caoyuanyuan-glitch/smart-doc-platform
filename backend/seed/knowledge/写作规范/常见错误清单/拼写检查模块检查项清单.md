# 拼写检查模块检查项清单

## 一、拼写错误（中文）

| 类型 | 错误示例 | 正确写法 | 说明 |
|------|---------|---------|------|
| 形近字 | 污然、转数、组份 | 污染、转速、组分 | 字形相近导致的误写 |
| 音近字 | 机率、做业 | 概率、作业 | 同音或近音替代 |
| 缺字/多字 | 进行行、可以可行 | 进行、可行 | 输入重复或漏打 |
| 生造词 | 可重复性好 | 重复性好 | 不符合术语规范的表达 |

## 二、拼写错误（英文）

| 类型 | 错误示例 | 正确写法 | 说明 |
|------|---------|---------|------|
| 拼写错误 | libaries、componets | libraries、components | 纯拼写错误 |
| 英式/美式混用 | optimised / color | optimized / colour | 全文应统一 |
| 常见混淆 | affect / compliment | effect / complement | 同音异义词 |

## 三、大小写规范

| 类型 | 错误示例 | 正确写法 | 说明 |
|------|---------|---------|------|
| 分子生物学缩写 | pcr、dna、rna | PCR、DNA、RNA | 全大写缩写 |
| 品牌名 | dnbelab、mgitech | DNBelab、MGI Tech | 专有名词首字母大写 |
| 产品型号 | t7、g99 | T7、G99 | 型号字母大写 |
| 单位大小写 | mL / ML | mL | 大小写含义不同 |
| 化学式 | co2、nacl | CO₂、NaCl | 元素符号大写 |
| 专有名词首字母 | rnase、taq | RNase、Taq | 按领域惯例 |

## 四、单位与数值格式

| 类型 | 错误示例 | 正确写法 | 说明 |
|------|---------|---------|------|
| 体积单位 | ul、uL、μl | μL | 希腊字母 μ + 大写 L |
| 时间单位 | mins、min. | min | 技术文档用 min |
| 转速 | rpm、rmp、RPM | r/min 或 rpm（统一） | |
| 温度 | 37℃、37 度 C | 37 °C | 数字+空格+°C |
| 浓度 | 10mM、10 mmol/L | 10 mM（空格+单位） | |
| pH | ph 8.0、PH 8.0、pH8.0 | pH 8.0 | 大小写+空格 |
| 数值范围 | 1.8-2.0、1.8~2.0 | 按规范统一 | 连字符/波浪号/一字线 |
| 数字千分位 | 1000000 | 1 000 000（GB）或 1,000,000（ASTM） | 按规范统一 |

## 五、数字与英文空格

| 类型 | 错误示例 | 正确写法 | 说明 |
|------|---------|---------|------|
| 数字+体积 | 5mL、10uL | 5 mL、10 μL | |
| 数字+长度 | 10bp、50nt | 10 bp、50 nt | |
| 数字+转速 | 12000rpm | 12 000 rpm | |
| 数字+吸光度 | OD260 | OD 260 | |
| 数字+稀释 | 1x、10X | 1×、10× | 乘号不是字母 x |

## 六、标点符号规范

| 类型 | 错误示例 | 正确写法 | 说明 |
|------|---------|---------|------|
| 冒号后空格 | 如下:1. | 如下：1. | 中文冒号后加空格 |
| 标点后空格 | a)避免 | a) 避免 | 右括号后空格 |
| 感叹号 | 请勿暴露于强光下! | ……强光下。 | 技术文档不用感叹号 |
| 省略号 | 非常重要…… | 非常重要。 | 不用省略号 |
| 引号混用 | 'primer' | "primer" | 统一直双引号 |
| 括号前空格 | PCR(Polymerase | PCR (Polymerase | 英文括号前空格 |
| 顿号/逗号 | Buffer, Enzyme和Primer | Buffer、Enzyme 和 Primer | 并列项用顿号（中文） |
| 破折号 | --、-、— | —（中文破折号占两格） | |

## 七、特殊字符规范

| 类型 | 错误示例 | 正确写法 | 说明 |
|------|---------|---------|------|
| 希腊字母 | uL、ul | μL | 不是拉丁字母 u |
| 度数符号 | 37C、37度 | 37 °C | 用 ° 不是 o 或 度 |
| 正负号 | +/- | ± | 技术文档用 ± |
| 乘号 | 10 x 5、10*5 | 10 × 5 | 用 × 不是 x 或 * |
| 波浪号 | ~ | ≈（约等于）或 —（范围） | 按语义区分 |
| 箭头 | ->、—> | → | 统一箭头符号 |
| 百分比 | 10 %、10 pct | 10%（无空格） | 按规范统一 |

## 八、格式统一性

| 类型 | 错误示例 | 正确做法 |
|------|---------|---------|
| 日期格式 | 2026-07-27、2026/07/27、2026.07.27 | 全文统一为一种 |
| 时间格式 | 09:00、9:00、上午9点 | 统一 24 小时制或中文 |
| 编号格式 | 1.、1)、(1)、① | 统一一种层级编号 |
| 列表标记 | 项目符号和编号混用 | 同层级统一 |
| 缩进/空格 | 段落有时两格有时没空格 | 全文统一 |
| 空行 | 章节间有时空一行有时空两行 | 统一间距 |
| 全角/半角 | 英文段落中混入全角标点 | 英文用半角、中文用全角 |
| 中英文混用 | 中文里嵌英文描述词 | 描述性文字用中文 |

## 九、技术文档特有

| 类型 | 错误示例 | 正确写法 | 判断依据 |

| 公司名称 | 华大基因 / BGI / MGI 混用 | 全文统一 | |
| 缩写未定义 | 首次出现 PBMC | 外周血单个核细胞（PBMC） | 首次给全称 |

## 十、信息完整性（基础校验）

| 检查项 | 校验逻辑 | 示例 |
|--------|---------|------|

| 待补充标记 | 文本含"（待补充）""（TBD）" | 直接标红提醒 |
| 版本号缺失 | 文档无版本号或修订日期 | 标红提醒 |
| 页眉页脚 | 页码/文档名/版本号不一致 | 跨页校验 |
| 目录与实际 | 目录章节与实际章节不匹配 | 结构校验 |

## 排除项（拼写检查**不应**管的）

以下属于文档审核模块（大模型）的范畴，拼写检查规则引擎**不做判断**：

| 类型 | 示例 | 为什么给大模型 |
|------|------|---------------|
| 逻辑矛盾 | 表3说5个组分实际4个 | 需要理解表格结构 |
| 步骤顺序错误 | 先加酶后加底物 | 需要理解实验逻辑 |
| 内容矛盾 | 储存条件2-8°C但写-20°C | 需要跨段落理解 |
| 信息缺失 | 缺少废弃物处理 | 需要理解规范要求 |
| 术语语义判断 | "反转录"在技术语境下是否合适 | 需要领域知识 |
| 表格数据计算 | 总量≠各组分之和 | 需要数学计算 |
| 交叉引用错误 | 引用图1但图1不存在 | 需要全局索引 |
