## 前置指令（优先级覆盖所有后续规则）

以下为润色时**必须逐句检查**的硬性规则，任何情况下不得违反：

1. **句子长度**：不含标点的句子构件不超过 20 字；完整句不超过 100 字（正文约 3 行）。超出则拆分。
2. **主动语态**：所有句子使用主动语态。反例"此软件尚未被安装"→"尚未安装此软件"。
3. **肯定句式**：使用肯定句，禁止双重否定。反例"没有权限的用户不能删除"→"用户必须具有删除权限才能删除"。
4. **界面元素**：所有菜单名、按钮名、字段名、选项卡名统一用【】包裹。如「点击确定」→「点击【确定】」。
5. **词语分离**："的/地/得"用法正确。产品型号内部字母数字不插入空格。
6. **单一段落主题**：每段只讲一件事，中心句放段首，不超过 7 行。
7. **句式学模板结构，内容保留原文**：句式清单的示例仅用于理解模板，不得替换原文中的词。

## 二、语法规范（逐句检查）

### 2.1 成分残缺

| 反例 | 正例 |
|------|------|
| 在应用程序没有提供会话保持的功能下，HAProxy 可以提供该项功能 | 在应用程序没有提供会话保持功能的情况下，HAProxy 可以提供该项功能 |

### 2.2 搭配不当

| 反例 | 正例 |
|------|------|
| HAProxy 是由 Linux 内核的核心贡献者 Willy Tarreau 于 2000 年编写，并仍然负责该项目的维护，该在开源社区提供免费和版本迭代 | HAProxy 是由 Linux 内核的核心贡献者 Willy Tarreau 于 2000 年编写，他现在仍然负责该项目的维护，并在开源社区免费提供版本迭代 |

### 2.3 成分多余

| 反例 | 正例 |
|------|------|
| 根据官方建议，目前稳定版本的 HAProxy 为稳定版 2.0 特性 | 官方目前建议使用 HAProxy 稳定版本 2.0 |

### 2.4 句式杂糅 → 拆分为短句

反例（一句包含多个主语和动作）：
> 当部署多个 DM-master 节点时，所有 DM-master 节点将使用内部嵌入的 etcd 组成集群并用于存储集群节点信息、任务配置等元数据，同时通过 etcd 选举出 leader 节点用于提供集群管理、数据迁移任务管理相关的各类服务。

正例（按主语拆分为独立短句）：
> 当部署多个 DM-master 节点时，所有 DM-master 节点将使用内部嵌入的 etcd 组成集群。该集群用于存储集群节点信息、任务配置等元数据，同时通过 etcd 选举出 leader 节点。该 leader 节点用于提供集群管理、数据迁移任务管理相关的各类服务。

### 2.5 歧义表达 → 展开明确化

| 反例 | 问题 | 正例 |
|------|------|------|
| 多个引物类型以英文分号分隔，无关顺序，但不可重复填写。例如【16S;18S】 | 举例可理解为可填写或不可填写 | 多个引物类型以英文分号分隔，无关顺序，但不可重复填写。例如，可填写【16S;18S】，但不可填写【16S;18S;16S】 |
| 配置管理界面 | 无上下文时"配置""管理"既是名词也是动词 | 补充上下文明确含义 |

## 四、标点符号（全文统一）

### 4.1 基础规则

| 规则 | 说明 |
|------|------|
| 中文全角标点 | 中文语句全部使用全角标点（。，、；：""''（）） |
| 英文半角标点 | 整句英文中使用半角标点 |
| 不混用 | 一段文字中不中英文标点混用 |

### 4.2 各标点用途

| 标点 | 用途 | 注意事项 |
|------|------|----------|
| 句号 `。` | 陈述句末尾 | 紧接图表时不用冒号 |
| 逗号 `，` | 句子内部停顿 | 禁止"一逗到底"，适时用句号断句 |
| 顿号 `、` | 并列词语间 | — |
| 分号 `；` | 并列分句 / 分项列举 | 分项时大项用句号、小项用分号 |
| 冒号 `：` | 引出列表/步骤/表格 | — |
| 方头括号 `【】` | **所有界面元素**（菜单、按钮、选项、字段、页签） | 如【确定】、【文件】>【保存】 |
| 感叹号 `！` | **仅用于严重安全警告** | 正文不使用 |
| 连接号 `-` | 外文词汇、电话号码 | 如 RJ-45、E-Mail |
| 波浪线 `~` | 数量范围 | 如 1~3 |
| 一字线 `—` | 汉语名词连接 | 如 压力—温度曲线 |

## 五、数字与单位

### 5.1 空格规则

| 场景 | 规则 | 示例 |
|------|------|------|
| 数值 + 单位符号 | 加半角空格 | 7 kg、8 MB、10 GB |
| 中文 + 英文 | 加半角空格 | PCR 模块、DNA 打断仪 |
| 角度、百分号、英尺英寸 | 不空格 | 60°、100%、4'5" |

### 5.2 组合单位

| 规则 | 说明 |
|------|------|
| 词头只加在第一个单位前 | kN·m（不是 N·km） |
| 不混用中文名和单位符号 | km/h（不是 km/小时） |
| 词头不得孤立使用 | 64 kbit/s（不是单独写 64 k） |
| 速率统一写法 | bit/s（不用 b/s 或 bps） |
| 字节速率 | byte/s 或 B/s |
| 计算机内存 | MB、GB、TB |

### 5.3 不规范的缩略单位（禁止）

| 反例 | 正例 |
|------|------|
| 10 w | 10 万 |
| 16c32g | 16 核、32 GB |
| 200μL | 200 μL |
| 4℃ | 4 ℃ |

## 六、句式规范

### 6.1 句子结构

| 规则 | 要求 |
|------|------|
| 句类 | 使用简单句和并列句，禁止复合句 |
| 语态 | 主动语态（"用户点击按钮"而非"按钮被用户点击"） |
| 句式 | 肯定句，禁止双重否定 |
| 非正式语言 | 禁止，如"酷毙了""给力"等口语化表达 |
| 冷僻词/生造词 | 禁止，如"唯二""尔等" |
| 文言文 | 禁止 |
| 的/地/得 | 严格区分：形容词+的+名词（开心的笑容）、副词+地+动词（开心地笑）、动词+得+副词（笑得开心） |

### 6.2 代词

代词（其、该、此、这）必须明确指代对象，保证全文只有一个含义。

反例：从管理系统可以监视中继系统和受其直接控制的分配系统。（"其"指代不明）

正例：从管理系统可以监视两个系统：中继系统和受中继系统直接控制的分配系统。

### 6.3 形容词

名词前不使用过多形容词，最多一个。

反例：此设备的使用必须在接受过本公司举办的正式的设备培训的技师的指导下进行。

正例：此设备必须在技师的指导下使用，且指导技师必须接受过由本公司举办的正式设备培训。

## 九、执行优先级（逐句检查顺序）

对每句原文按以下顺序逐项检查并修正：

1. **术语替换**：非标准术语 → 标准术语（用户术语库）
2. **禁用词**：直接删除推销词、程度副词、转折词、模糊量词
3. **界面元素**：所有 UI 名称加【】，连续操作用 > 连接
4. **数字单位**：数值与单位间加空格，修正不规范缩略单位
5. **语法修正**：成分残缺→补全、搭配不当→修正、成分多余→删除、句式杂糅→拆分
6. **句长控制**：构件≤20字、完整句≤100字，超出拆分为短句
7. **语态句式**：被动→主动、双重否定→肯定
8. **标点**：中文全角、句尾补全、禁止一逗到底
9. **拼写**：简繁统一、英文大小写、的/地/得
10. **代词**：指代不明→明确写出
