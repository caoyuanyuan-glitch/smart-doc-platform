人工审核意见汇总工具 — 同事操作步骤

本工具扫描文件夹里的 PDF 注释和 Word（.docx）批注，汇总成 Markdown，
并为需要看图的批注生成 JPEG 截图。


一、第一次使用（每台电脑做一次）

1. 把整个 zip 拷到本地硬盘，右键 zip -> 属性 -> 勾选「解除锁定」-> 确定。
2. 解压到任意文件夹，例如 D:\审核意见汇总工具\ 。请保持文件夹完整，文件不要拆开。
3. 安装官网 Python 3：https://www.python.org/downloads/
   安装时勾选 Add python.exe to PATH。
   请用 python.org 安装包，跳过微软应用商店里的 Python。
4. 打开「命令提示符」（cmd），运行：
   py -m pip install PyMuPDF


二、每次汇总

1. 双击「打开审核意见汇总工具.hta」（会先出现启动窗口）。
   备选：start_extractor.vbs
   再备选：打开审核意见汇总工具.cmd（会闪一下黑框，属正常）
2. 模式保持「提取 PDF/Word 批注」。
3. 输入：点【选择文件夹】，选审核材料所在的最上层目录
   （例如 F:\内部审核意见汇总1026\ ，里面直接放各 PDF）。
4. 输出：可直接改文件名，例如 人工审核意见汇总cyy.md
   也可点【保存为】选位置。建议保存在输入文件夹里。
5. 点【开始汇总】，等完成弹窗。


三、跑完后得到什么

在输出 md 旁边（以及输入根目录下）会有：

  人工审核意见汇总cyy.md
  人工审核意见汇总cyy.part1.zip     （发给后续整理/AI 用这个）
  批注截图\H-020-000618-00_p10_ann6.jpg

说明：
- Markdown 里每条批注有：覆盖文本、原文、人工意见、矩形坐标。
- 只有需要看图的批注才有截图；文本类意见（逗号、拼写、中英文不一致等）无截图。
- 截图都在「输入根目录\批注截图\」，文件名带货号。无货号时用完整文件名，重名会加 _2、_3。
- 超过约 30MB 会拆成 .part1.zip、.part2.zip，每个包里都有完整 md。
- 「合并 Markdown」模式只生成 md，不打包 zip。


四、换一批材料再跑之前

请先手动删掉输入根目录下旧的「批注截图」文件夹，以及各 PDF 同名文件夹里残留的「批注截图」。
否则新结果会和旧图混在一起。


五、启动没有窗口

把工具目录里的这两个文件发回来即可：
  annotation_extractor_launch.log
  annotation_extractor_error.log（如有）
