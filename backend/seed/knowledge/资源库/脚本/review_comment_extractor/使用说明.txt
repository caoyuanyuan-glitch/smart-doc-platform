人工审核意见汇总工具 v30 — 同事操作步骤

本工具扫描文件夹里的 PDF 注释和 Word（.docx）批注，汇总成 Markdown，
并为需要看图的批注生成 JPEG 截图。请用浏览器打开同名 .html 查看（Word 打开 md 看不到 html）。


一、第一次使用（每台电脑做一次）

1. 把整个 zip 拷到本地硬盘，右键 zip -> 属性 -> 勾选「解除锁定」-> 确定。
2. 解压到任意文件夹，例如 D:\审核意见汇总工具_v30\ 。请保持文件夹完整，文件不要拆开。
3. 安装官网 Python 3：https://www.python.org/downloads/
   安装时勾选 Add python.exe to PATH。
   请用 python.org 安装包，跳过微软应用商店里的 Python。
4. 打开「命令提示符」（cmd），运行：
   py -m pip install PyMuPDF


二、每次汇总

1. 双击「打开审核意见汇总工具.hta」（会先出现启动窗口）。
   备选：start_extractor.vbs
   再备选：打开审核意见汇总工具.cmd（会闪一下黑框，属正常）
2. 模式保持「提取 PDF/Word 批注」。
3. 输入：点【选择文件夹】，选审核材料所在的最上层目录
   （例如 F:\内部审核意见汇总1026\ ，里面直接放各 PDF）。
4. 输出：可直接改文件名，例如 人工审核意见汇总cyy.md
   也可点【保存为】选位置。建议保存在输入文件夹里。
5. 点【开始汇总】，等完成弹窗。
   弹窗会给出 HTML 路径；请用 Chrome / Edge 打开该 html。


三、跑完后得到什么

在输出 md 旁边（以及输入根目录下）会有：

  人工审核意见汇总cyy.md
  人工审核意见汇总cyy.html
  人工审核意见汇总cyy.zip            （发给后续整理/AI 用这个；超过 35MB 才是 .part1.zip、.part2.zip）
  批注截图\H-020-000618-00_p10_ann6.jpg

说明：
    - Markdown 开头有分类统计和分类索引，方便发给 AI 整理。
    - 每条批注有：文档号、建议分类、框选还原、定位原文（**【】** 标出问题位置）、人工意见。
    - 小框选只高亮框内文字，不把整行标黄。
    - 框选到正文时，定位原文一定用 **【】** 标出框选文字。
    - 纯文本框选（拼写、标点、中英文不一致、用词等）只高亮框内文字，不出图。
    - 框选为空时生成截图，定位原文不标图注数字或整句。
    - 空框选必须带截图，即使人工意见是文本类（如「当」「中英文不一致」）。
    - 空框选只出截图，不把旁边未被框住的词标黄。
    - 用浏览器打开 html；原文里的【控件名】不会截断黄标。
    - 框选碎片会还原成完整词/短语，例如「部储存设」写成「外部储存设备」。
    - 跨行框选会补成完整词，例如「based compression」写成「reference-based compression」。
    - 点在 Tips/注意/提示 标题上的批注，会高亮该标题，并带上对应提示正文和上方步骤。
    - zip 只包含汇总 md、html 和批注截图，不含 json 等其它文件。
    - 只有需要看图的批注才有截图；文本类意见（逗号、拼写、中英文不一致等）无截图。
    - 截图都在「输入根目录\批注截图\」，文件名带货号。无货号时用完整文件名，重名会加 _2、_3。
    - 截图文件名带货号和编号，例如 H-020-000618-00_p10_ann6.jpg。
    - 截图裁的是批注附近一整段上下文（接近页宽），只保留 PDF 里原有的批注外观。
    - zip 总体不超过约 35MB 时只打一个包；超过才按约 35MB 装满后拆卷，每个分卷里都有完整 md 和 html。
    - 「合并 Markdown」模式生成 md 和 html，不打包 zip。


四、换一批材料再跑之前

请先手动删掉输入根目录下旧的「批注截图」文件夹，以及各 PDF 同名文件夹里残留的「批注截图」。
否则新结果会和旧图混在一起。


五、启动没有窗口

把工具目录里的这两个文件发回来即可：
  annotation_extractor_launch.log
  annotation_extractor_error.log（如有）
