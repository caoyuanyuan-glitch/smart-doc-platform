# Agent 接入平台知识库 · 实现与实测说明

日期：2026-11-19　审核工具：WorkBuddy

## 一、做了什么

把浮动 Agent 的「智能问答」意图从**纯通用模型知识**升级为**平台知识库 RAG 问答**：

```
用户提问 → Agent 意图识别为 qa → 检索平台知识库 →
  ├─ 命中且相关 → 用检索片段作为上下文让模型作答 → 附来源引用
  └─ 未命中/低分/异常 → 回退通用知识回答（原有行为不变）
```

### 改动文件

| 文件 | 改动 |
|---|---|
| `backend/app/api/agent.py` | 新增 `_answer_from_knowledge()`（复用 qa.py 检索链路）；`_dispatch` 加 `db` 参数，qa 分支改为知识库优先+通用回退，响应新增 `sources`/`answer_source`；`agent_chat` 注入 `db`；加开关 `REVIEW_AGENT_KB_QA` |
| `frontend/src/components/AgentDock.vue` | 消息对象接收 `sources`/`answerSource`，气泡下方渲染「参考来源」标签（hover 显示片段摘要） |
| `backend/tests/test_agent_kb_qa.py` | 5 例分流测试（命中/回退/空问题/开关/无 db） |
| `backend/tests/manual/agent_kb_probe.py` | 真实 DeepSeek 调用的 RAG 实测探针，可复跑 |

### 复用的现有能力（未重写）

 Agent 内部直接调用问答页完全相同的四个函数，保证两处口径一致、无重复实现：

- `qa._load_qa_documents(db, [])` — 加载知识文档（自动排除「AI agent知识库」目录）
- `qa._rank_document_chunks()` — jieba 打分排序（纯本地，无 ES/向量依赖）
- `qa._build_context_from_sources()` — 组装上下文 + 归一化来源
- `qa._call_ai_qa()` — 带来源标注的作答，含三级降级链

## 二、实测结果（真实 DeepSeek 调用，非 mock）

> 环境说明：本沙箱无法写入 `~/.smart-doc-platform/knowledge/`（Permission denied），seed 复制的文件为空。探针改为直接读 `seed/knowledge/` 源文件构造 documents，模拟"知识库已正常加载"状态，验证 RAG 链路本身。这是环境限制，非代码缺陷；在正常部署环境（可写用户目录）seed 会正常落盘。

| 问题 | 检索命中 | top 分 | 结果 |
|---|---|---|---|
| 测序仪操作手册的图片有什么要求？ | 8 | 16.85 | ✅ 基于知识库作答，3 来源（含"仪器图宽度≤143mm"等精确内容） |
| 技术文档里日期和时间用什么格式？ | 8 | 24.60 | ✅ 基于知识库作答，3 来源 |
| 说明书中危险和警告类提示应该怎么写？ | 8 | 20.15 | ✅ 基于知识库作答，2 来源（危险/警告/注意的定义） |
| 全角标点在术语里怎么用？ | 8 | 14.95 | ✅ 客观回答"未找到直接规定"并列出相关规范，5 来源 |
| 今天天气怎么样？ | 0 | 0.00 | ✅ 正确判定无命中 → 回退通用知识 |

**结论：知识类问题全部走 RAG 并带来源；无关问题正确回退。** 分流逻辑符合预期。

## 三、配置项

```env
# 设为 0/false/no 可关闭 Agent 知识库问答，回到纯通用问答（默认开启）
REVIEW_AGENT_KB_QA=1
```

- 鉴权：Agent 端点与问答页共用同一 Bearer JWT；Agent  stricter（要求 active 用户），已注入 `db` 与鉴权依赖。
- 知识范围：与问答页一致（写作规范 + 资源库，排除「AI agent知识库」）。
- 无外部依赖：检索是本地 jieba 打分，只有作答环节调模型；模型不可用时 `_call_ai_qa` 有降级链。

## 四、已知边界（如实说明）

1. **软拒答字符串**：`_call_ai_qa` 可能返回"文档中未找到关于…的直接规定"这类表述，它不等于精确的"文档中未找到相关信息"，因此不会被判为回退，而是作为带来源的正常回答返回。实测第 4 题即此情况——回答客观、有来源，可接受。若希望这类也回退，可把判断改为前缀匹配 `startswith("文档中未找到")`。
2. **沙箱路径限制**：见上，需在可写用户目录的正常环境验证完整 seed→检索链路。
3. **测试偏差**：5 个问答是我设计的，存在"自出题自答"偏差；上线后建议用真实用户输入复测。
