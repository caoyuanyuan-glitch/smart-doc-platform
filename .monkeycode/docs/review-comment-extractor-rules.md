# 人工审核意见汇总：高亮与截图规则

- Date: 2026-11-04
- 工具：`backend/scripts/review_comment_extractor/`（当前对外版本 v30）
- 用途：抽取 PDF/Word 批注时，定位原文高亮和截图的判定口径。改工具时以本文件为准。

## 统一口径

按「框里有没有字」走一条链路：

1. 框里有正文：定位原文用 `**【框选文字】**` 标出框选位置。拼写、标点、中英文不一致、用词等纯文本意见到此结束，不出图。版式、图、图标类意见在高亮之外再出图。
2. 框里没字（空框）：定位原文不标黄，必须出图。人工意见即使是「当」「中英文不一致」也出图。
3. Caret 插入：定位原文标 `【^】`，并出图。

短词（如版本号里的 `B`、数字 `6`、术语 `ID`）只要框里抽到，就按第 1 步高亮。

## 高亮细节

- 只标框选还原的那一处，不把整句、整行标黄。
- 同词多处时，标框选所在位置，用框选左右锚点区分。
- 框选碎片还原成完整词/短语后再标，例如「部储存设」写成「外部储存设备」；跨行只补被截断的词。
- 空框不把旁边未被框住的词标黄，也不标图注数字或整句。
- HTML 把成对 `**【…】**` 转成黄标；原文里的 `【控件名】` 保持原样。

## 截图细节

- 截图文件名：`{货号}_p{页}_ann{序号}.jpg`，放在输入根目录 `批注截图/`。
- 裁批注附近一整段上下文（接近页宽）。
- 只渲染 PDF 原注释外观，不另画矩形。
- 定位原文过短、表格折行碎片看不懂时，按视觉问题出图；有框选文字时仍然高亮。
- 点在 Tips/注意/提示 标题上的批注：高亮该标题，并带提示正文；需要看图时出图。

## 打包

- 发给后续整理/AI 的 zip 只含同名 md、html 和 `批注截图/*.jpg`。
- 总体不超过约 35MB 打成一个 `{stem}.zip`；超过才按约 35MB 装满后拆 `.part1.zip`、`.part2.zip`。
- 每个分卷都带完整 md 和 html。
- HTML 用相对路径 `批注截图/xxx.jpg` 引用截图。
