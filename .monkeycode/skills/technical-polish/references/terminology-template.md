# 术语库模板

术语库用于定义非标准术语到标准术语的映射关系。用户通过 Markdown 文件或 Excel 文件提供。

## Markdown 表格格式

### 简单格式（推荐）

```markdown
| 非标准术语 | 标准术语 |
|-----------|---------|
| 枪头 | 吸头 |
| 移液枪 | 移液器 |
| 机械手 | 机械臂 |
| 样品 | 样本 |
| 切勿 | 请勿 |
```

### 中英双语格式

```markdown
| 非标准(中) | 标准(中) | 非标准(英) | 标准(英) |
|-----------|---------|-----------|---------|
| 枪头 | 吸头 | tip | pipette tip |
| 移液枪 | 移液器 | pipette gun | pipettor |
```

### 带语言列格式

```markdown
| 非标准 | 标准 | 语言 |
|--------|------|------|
| tip | pipette tip | en |
| 枪头 | 吸头 | zh |
```

## Excel 格式

Excel 文件第一列"非标准术语"，第二列"标准术语"。

## 术语使用规则

1. **强制替换**：文档中出现非标准术语时，必须替换为标准术语
2. **词边界匹配**：完整词边界匹配，避免局部误替换（如不把"手枪头"匹配成包含"枪头"）
3. **按语言过滤**：中文文本只匹配中文术语，英文只匹配英文
4. **文件优先**：用户上传的术语文件优先级高于平台内置术语
5. **大小写敏感**：英文术语按原样匹配

## 示例

原始文本：
> 使用移液枪将枪头插入样品管中。

润色后：
> 使用移液器将吸头插入样本管中。
