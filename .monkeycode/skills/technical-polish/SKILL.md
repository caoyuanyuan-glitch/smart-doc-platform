# 技术文档智能润色

对中文技术文档执行全面智能润色：语法校对、术语规范化、风格优化，输出原文与润色结果的逐句对比视图。

## 工作流

### 1. 接收输入

接收用户提供的待润色内容，确认以下信息：
- **待润色文本**：直接粘贴文本或上传文档文件（DOCX、PDF、Markdown、XML）
- **术语库文件**（可选）：Markdown 或 Excel 格式的术语对照表，见 `references/terminology-template.md`
- **句式清单文件**（可选）：句式模板参考手册

### 2. 解析文档

- **纯文本/Markdown**：直接使用，不做额外解析
- **DOCX**：使用 python-docx 或 docx2txt 提取纯文本段落
- **PDF**：使用 pdfplumber 或 PyMuPDF 提取文本
- **XML**：解析 XML 结构，提取文本节点内容

### 3. 加载润色规则

- 读取 `references/style-guide.md` 获取内置风格指南规则
- 如果用户提供术语库文件，解析术语映射表（格式见 `references/terminology-template.md`）
- 如果用户提供句式清单文件，提取句式模板

### 4. 执行润色

按以下优先级逐句处理待润色文本：

1. **术语替换**（最高优先级）：将非标准术语替换为标准术语
2. **句式匹配**：参照句式清单改写句式结构
3. **风格规范**：按写作风格指南修正禁用词、标点、格式
4. **微调优化**：被动语态、双重否定、句子长度的微调

每个步骤严格遵循：
- 句式学模板结构，内容保留原文的具体名称和参数
- 示例仅用于理解模板语法，不得替换原文中的词
- 原文没有提到的设备名、试剂名、步骤名，一律不得添加

### 5. 输出对比视图

将润色结果以逐句对比形式输出，格式：

```
## 润色结果

### 原文 vs 润色后

| # | 原文 | 润色后 | 变更说明 |
|---|------|--------|----------|
| 1 | 使用移液枪将枪头插入样品管 | 使用移液器将吸头插入样本管 | 术语替换：移液枪→移液器，枪头→吸头，样品→样本 |
| 2 | 机器的最佳性能 | 仪器的最佳性能 → 仪器性能 | 禁用词：删除"最佳"（禁止使用最高级评价词） |
```

每条变更说明需引用对应的规则来源。

## 内置风格指南

见 `references/style-guide.md`，包含：
- 禁用词列表
- 中文标点符号规范
- 数字与单位空格规则
- 语法规范（成分残缺、搭配不当、句式杂糅等）
- 产品型号字母数字连续书写规则

## 术语库格式

见 `references/terminology-template.md`，支持 Markdown 表格和 Excel 两种格式。术语替换优先使用用户指定的文件，未指定的术语按内置规则处理。
